# Todo Calendar

A todo calendar desktop app built with React + Electron.

## Install

```bash
npm install
```

> If you are behind a firewall or corporate proxy that requires a custom npm registry,
> configure your local `.npmrc` before running install. `.npmrc` is git-ignored and
> never committed — configure it however your environment requires.

## Develop

```bash
npm run dev        # Electron + Vite hot reload
npm run dev:web    # Web browser only
```

## Build & Package

```bash
npm run build      # Production build → dist/
npm run pack       # Electron app → dist-electron/ (unpacked, fast)
npm run dist       # Full installer (dmg / exe / AppImage)
```
